# censo-es-dataset

## Data provenance

Datasets present in upstream/caj_esp_* were downloaded from the INE website here:
https://www.ine.es/dyngs/DAB/es/index.htm?cid=1390. There is documentation for the file
formats in use in @docs/llm_analysis.

Additionally, the upstream documentation for the file formats is present in the
following files:

- @upstream/Dis_nuevo.xlsx: file structure for the file format.
- @upstream/dis_registro.pdf: seems to be another file format description.
- @upstream/cod_ccaa.csv: confirms the autonomous community distribution
- @upstream/cod_provincia.csv: confirms the provinces distribution. This is juicy because these codes are used in many places (first two digits of a Spanish postal code, for instance.)
- @upstream/cod_mun.csv: confirms the list of municipalities of Spain, crossed against the autonomous community (@upstream/cod_ccaa.csv) and province (@upstream/cod_provincia.csv).
- @upstream/TiposVia.csv: encodes the different street types. Just in case.

When a query about the INE datasets is made, you should use the following sources:

- @docs/llm_analysis. This is a set of report files that was cautiously generated by an LLM in xhigh reasoning mode. Use them as data source, because this data is very distillated.
- @upstream/caj_esp_*/*. If they are extracted, you can use them directly.
- @upstream/caj_esp_*.zip. Use them only if you don't find extracted distributions first.
- @upstream. Other CSV, PDF and Excel files you might find in the directory.
